# Coin game

Before lesson 0, have your own verified GitHub account, Git 2.31+ and school-approved access/privacy. Read the [account and privacy setup](https://zero.codepet.ca/docs/setup#before-lesson-0-github-and-privacy). Choose Private unless teacher/school policy says otherwise, invite your teacher as a collaborator and verify access; collaborators can edit. Use a teacher-approved commit identity and the exact GitHub noreply email for email privacy. Publishing is optional/public; private-repository Pages depends on the plan. No paid plan is needed for tutorial source work.

Create your own GitHub repository from the published tutorial template, then copy YOUR repository’s HTTPS URL. Sign in to Zero and choose **Project → Clone from GitHub…**. Paste that URL in **Clone from GitHub**. In **Clone location**, keep the default ~/Zero Projects or choose another folder outside any Git repository, then choose **Clone here**. Zero opens the clone in the current window. For an already-cloned Zero folder, use **Project → Open local project…** to open it in the current window without cloning again. A ZIP or a folder inside another repository cannot start this tutorial.

Keep using your repository for lessons 8–12 as you write your own code. The scaffold contains only setup and an empty Main; the first run opens a blank window or canvas.

Open src/main/java/Main.java and read the [first lesson](https://zero.codepet.ca/tutorials/8). After edits, click **Run App again**. Run uses local Git checks and needs no GitHub sign-in. Sign in when you want to Commit & push, start a New branch, or Merge to main. Submit your repository link separately in Pika.

Lesson 11 uses the tutorial-credits-badge practice library from the Coin game. Keep other ZeroHub contributions in a separate original project.
